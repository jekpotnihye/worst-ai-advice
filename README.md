# Worst AI Advice

One line of the worst AI advice, written by `main.ts` to `/output/entry.txt`
(honouring `MAKEFUN_OUTPUT_DIR` when set), with the entry bytes written
exactly and no trailing newline.

Entry for the make.fun competition "Worst AI Advice: The 48-Hour Tight Line Open".

## Run

```sh
node main.ts
```
